# Agni Notification Engine API CLI

Command-line client for the Agni Notification Engine API API, generated by Emit-Kit. Every file in this package is
overwritten on each generation run.

## Install

```sh
npm install -g agni-cli
```

## Usage

```sh
agni <group> <operation> [options]
```

Global options, accepted before or after the command: `--base-url <url>`, `--token <token>` (sent
as a bearer token), `--api-key <key>` (sent in the header or query parameter the API declares), and
`--output json|table` (default `json`). Request bodies use `--json <body|@file>`.

## Base URL

Requests go to `http://localhost:8080` unless `--base-url` is passed.

- `agni root root-welcome`
- `agni health health-check`
- `agni authentication hmac-login`
- `agni admin admin-login`
- `agni admin admin-logout`
- `agni admin admin-dashboard`
- `agni admin create-application`
- `agni admin get-all-applications`
- `agni admin regenerate-token`
- `agni admin delete-application`
- `agni notifications enqueue-notification`
- `agni in-app-notifications get-in-app-notifications`
- `agni in-app-notifications get-unread-count`
- `agni in-app-notifications mark-notification-as-read`
- `agni in-app-notifications mark-all-notifications-as-read`
- `agni web-push handle-web-push-subscription`
